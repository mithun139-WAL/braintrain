# STEP 4: Gradual Migration Strategy
# ═══════════════════════════════════════════════════════════════════════════

"""
You can migrate gradually by:

1. **Phase 1: Parallel Operation**
   - Keep existing VoiceAgent logic
   - Run orchestrators in parallel
   - Compare outputs, log differences
   - Use orchestrator decisions for metrics only

2. **Phase 2: Hybrid Mode**
   - Use orchestrators for evaluation only
   - Keep existing turn logic
   - Validate orchestrator evals match existing

3. **Phase 3: Orchestrator Primary**
   - Use orchestrator decisions for actions
   - Keep existing logic as fallback
   - Switch based on feature flag

4. **Phase 4: Full Migration**
   - Remove old logic
   - Orchestrators fully control flow
   - VoiceAgent becomes transport only

Example hybrid mode:
```python
USE_ORCHESTRATORS = os.getenv('USE_ORCHESTRATORS', 'false') == 'true'

async def handle_transcript(self, transcript: str):
    if USE_ORCHESTRATORS:
        # Let orchestrators handle via events
        await self.event_bus.emit(Event(
            type=EventType.TRANSCRIPT_RECEIVED,
            session_id=self.room_name,
            payload={"transcript": transcript}
        ))
    else:
        # Use existing logic
        await self.legacy_handle_transcript(transcript)
```
"""

@router.get("/orchestrators/health")
async def orchestrator_health(
    agent: VoiceAgent = Depends(get_active_agent)
):
    '''Check orchestrator health.'''
    
    if not hasattr(agent, 'orchestrator_hub'):
        return {"status": "disabled"}
    
    hub = agent.orchestrator_hub
    
    # Check model health
    model_stats = hub.model_orchestrator.get_provider_stats()
    unhealthy_providers = [

        if stats["health"] < 0.8

# TROUBLESHOOTING
# ═══════════════════════════════════════════════════════════════════════════

"""
Common Issues:

1. **Events not being processed:**
   - Check event_bus.register_event_handlers() was called
   - Verify events are being emitted with correct EventType
   - Check logs for exceptions in event handlers

2. **Missing session state:**
   - Ensure initialize_session() was called before first transcript
   - Check session_id matches between initialization and events

3. **High latency:**
   - Check model provider health in stats
   - Look for network issues to LLM providers
   - Verify parallel execution is working (not sequential)

4. **Hallucination warnings:**
   - Review VerifiedCandidateProfile extraction
   - Check if resume_text is being properly loaded
   - Verify generation prompts don't encourage invention

5. **Evaluation disagreements:**
   - Check rule-based metrics calculation
   - Verify LLM evaluation prompt is clear
   - Review phase-specific weights

Debug mode:
```python
import logging
logging.getLogger('app.ai.orchestrators').setLevel(logging.DEBUG)
```
"""
